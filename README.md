# EVA Clipper

Запись игр и мгновенный повтор для Windows. Один момент — отдельные видео экрана, игры, Discord, браузера и дополнительного окна, с отдельными аудиодорожками. Панель открывается справа по **Alt+X**.

## Скачать

Скачайте **EVA-Clipper-3.1.0-Windows-x64.zip** из [последнего релиза](https://github.com/theEVAai/eva-clipper/releases/latest), распакуйте целиком в доступную для записи папку и запустите **EVA Clipper.exe**. Папка `engine` должна оставаться рядом. Для обновления сохраните повтор, завершите EVA через трей и замените файлы приложения всем содержимым архива. Настройки версии 2 сохраняются; две версии одновременно запускать не следует.

Нужны Windows 10 2004 или новее / Windows 11, .NET Framework 4.8 и NVIDIA NVENC. Если не хватает системной библиотеки, установите [Microsoft Visual C++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe). Число кодировщиков и режимы зависят от видеокарты и драйвера. AMD/Intel-кодировщики не реализованы. EXE не подписан.

## Пропущенные моменты

В настройках «Источники» включите **«Сохранять окна отдельными видео»**. EVA ищет последнюю активную игру, Discord и браузер; можно выбрать конкретные окна и четвёртый дополнительный источник. Всего: монитор плюс до четырёх окон.

Откройте нужную демонстрацию в Discord, при необходимости вынесите её в отдельное окно. **Alt+Shift+F10** включает повтор. **Alt+F10** сохраняет все доступные буферы в одну папку внутри `Моменты`. Галерея открывает весь момент, чтобы выбрать видео.

- Перекрытое окно может записываться в фоне. Свёрнутое отмечается как недоступное: в уже работающем видео будет пустой участок, звук приложения продолжится. Закрытое окно не запускает новый буфер; EVA ждёт его появления.
- Discord должен отображать трансляцию: EVA не подключается к звонку и не запускает просмотр. Браузер записывает отображаемую вкладку выбранного окна, а не все скрытые вкладки.
- Автовыбор игры — эвристика; при ошибке выберите окно вручную. Эксклюзивный полный экран может потребовать безрамочного режима.
- Если источник недоступен, остальные записи сохраняются. Панель и `moment.json` сообщают об ограничении.

Файлы получают общую команду сохранения/остановки. Их начало может отличаться из-за появления окна, запуска кодировщика и ключевых кадров. `moment.json` содержит длительности и **приблизительные смещения для совмещения концов** в монтаже; это не покадровая синхронизация. Без `ffprobe` длительности и смещения имеют значение `null`.

## Звук

В режиме отдельных видео каждый файл содержит шесть AAC-дорожек:

| № | Содержание |
| --- | --- |
| 1 | Общий системный звук, можно отключить |
| 2 | Микрофон |
| 3 | Приложение игрового источника |
| 4 | Discord / приложение второго источника |
| 5 | Браузер / приложение третьего источника |
| 6 | Дополнительное приложение |

Захватывается звук приложения, а не отдельной вкладки или участника звонка. У источников своя громкость; у микрофона — отдельные устройство, громкость и выключатель. Система уже включает звук приложений: не складывайте её с теми же отдельными дорожками, если не нужен двойной звук. Пустые дорожки содержат тишину. Проигрыватель часто воспроизводит только одну дорожку; для всех дорожек нужен видеоредактор.

В режиме одного видео остаются общий микс, система и микрофон отдельно, либо до шести дорожек с четырьмя выбранными приложениями.

## Управление

| Действие | По умолчанию |
| --- | --- |
| Показать / скрыть панель | Alt+X |
| Начать / остановить обычную запись | Alt+F9 |
| Включить / выключить повтор | Alt+Shift+F10 |
| Сохранить весь момент | Alt+F10 |
| Снимок PNG | Alt+F1 |
| Включить / выключить микрофон | Ctrl+Alt+M |

Сочетания меняются в настройках; конфликты показываются в панели. Крестик и Esc скрывают панель, полный выход — через трей. Панель видна в записи рабочего стола, снимках и демонстрации всего экрана. Приложение не обходит ограничения защищённого контента Windows.

Обычная запись и повтор работают одновременно. Для смены источников, устройств и качества сохраните момент и остановите оба режима. Автовключение повтора при запуске и анимация панели настраиваются.

## Качество, память, файлы

Основное качество: до 3840×2160, 30/60/120 FPS, H.264/HEVC, 5–100 Мбит/с. Дополнительное: 720p/1080p, 30/60 FPS, 3–30 Мбит/с. FPS окна не превышает основной. По умолчанию: экран и игра 1080p60 / 24 Мбит/с, Discord и браузер 1080p30 / 8 Мбит/с; повтор 3 минуты. Микрофон и автоудаление выключены.

Повтор хранит сжатое видео в RAM. Одно ядро обслуживает все источники; закрытые окна не запускают кодировщик, загрузка миниатюр ограничена, соединение управления переиспользуется. Дополнительные активные видео всё равно увеличивают расход памяти. Например, 13 минут при 24 Мбит/с — около 2,3 ГБ только видеоданных одного источника, плюс звук и служебная память. Настройки показывают суммарную оценку буферов, нижняя строка — текущую память ядра. Для экономии уменьшайте длительность/битрейт и отключайте ненужные источники. Длительность 1–60 минут; предел основного буфера 16 ГБ, дополнительного — около 9,5 ГБ.

Папка по умолчанию — `Видео/EVA Clips`, её можно изменить. Очистка по возрасту/объёму касается только собственной библиотеки EVA. Закреплённые и самый новый момент защищены целиком; лимит может быть превышен. Посторонние файлы не удаляются.

Для миниатюр и длительностей нужны пользовательские `ffmpeg.exe` и `ffprobe.exe` в `PATH` или подпапке `tools`. Они не включены в архив; сама запись работает без них.

## Панель и рамки захвата

Панель шириной 440 px использует кремовый, чёрный и синий цвета EVA. Колёсико только прокручивает страницу настроек; значения меняются кликом, перетаскиванием или стрелками. Вкладки и кнопка применения остаются на месте.

«Захват окон без жёлтой рамки» включён по умолчанию. На Windows 10 ниже сборки 20348 Discord и браузер записываются через отдельный модуль PrintWindow, а автоматическая игра — через OBS Game Capture. В более новых Windows используется поддержка захвата без рамки в WGC. PrintWindow подходит не каждому приложению: если конкретное окно показывает чёрный кадр, выключите этот режим в настройках источников. При этом Windows 10 снова может показывать рамку. Свёрнутое окно не записывается. Частота поступающих кадров зависит от приложения и может быть ниже частоты кодирования.

## Локальные данные

Настройки, библиотека и миниатюры: `%LOCALAPPDATA%/EVA Clipper 2` (путь сохранён для совместимости). Конфигурация и журналы ядра: `engine/config`. Записи: выбранная папка. Эти данные не входят в репозиторий/релиз.

EVA использует собственную переносимую копию OBS и не меняет профиль другого OBS. WebSocket управления получает случайные порт и пароль при каждом запуске. Клиент подключается к `127.0.0.1`; сервер может слушать все IPv4-интерфейсы. Правила брандмауэра не добавляются. Не публикуйте `engine/config`: там локальные пути, устройства и пароль управления.

## Сборка и проверка

Windows, .NET Framework 4.8, современный Roslyn `csc.exe`:

```powershell
./scripts/build.ps1 -Compiler '<Roslyn>/csc.exe'
./scripts/check.ps1 -Compiler '<Roslyn>/csc.exe'
./scripts/package.ps1 -ObsZip '<downloads>/OBS-Studio-32.0.4-Windows-x64.zip' -ObsSource '<downloads>/OBS-Studio-32.0.4-Sources.tar.gz' -SourceRecordZip '<downloads>/source-record-0.4.8-windows.zip' -SourceRecordSource '<downloads>/source-record-0.4.8-Sources.tar.gz'
```

Контрактные проверки используют временную библиотеку, без записи или устройств. Дополнительно локально проверены пять одновременных видео, HEVC 120/30 FPS, шесть AAC-дорожек с четырьмя изолированными тестовыми приложениями, громкость, повтор во время обычной записи, изменение размера/сворачивание окна и захват перекрытых Discord/браузера. Это не длительный игровой тест и не проверка конкретной трансляции Discord.

Упаковщик проверяет хеши исходных архивов и берёт файлы из чистых дистрибутивов. Установленное приложение, runtime-конфигурация, отладочные символы и локальные данные не упаковываются. Не запускайте приложение в папке подготовки релиза. Оболочка — MIT; лицензии и соответствующие исходники OBS и Source Record прилагаются отдельно. См. [THIRD_PARTY.md](THIRD_PARTY.md).

Модуль захвата собирается MSVC x64 и Windows SDK: `./scripts/build-native.ps1 -ObsSourceRoot <распакованные исходники OBS 32.0.4>`. Перед упаковкой должны существовать оба файла: `build/EVA Clipper.exe` и `build/eva-window-capture.dll`.
