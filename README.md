# EVA Clipper

Запись рабочего стола и игр для Windows: обычная запись, мгновенный повтор и выдвижная панель справа. Отдельное приложение с ядром OBS Studio.

## Скачать и запустить

1. Откройте [последний релиз](https://github.com/theEVAai/eva-clipper/releases/latest).
2. Скачайте **EVA-Clipper-2.1.0-Windows-x64.zip** и распакуйте целиком в доступную для записи папку.
3. Запустите **EVA Clipper.exe**. Папка `engine` должна оставаться рядом с EXE.

Нужны Windows 10 2004 или новее / Windows 11, .NET Framework 4.8, актуальный драйвер NVIDIA и видеокарта с NVENC H.264/HEVC. При ошибке отсутствующей библиотеки установите официальный [Microsoft Visual C++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe). Аппаратные режимы зависят от видеокарты; AMD/Intel-кодировщики сейчас не реализованы. EXE не подписан цифровой подписью.

По умолчанию: 1080p, 60 FPS, H.264, 24 Мбит/с, повтор 3 минуты. Микрофон выключен. Автоудаление выключено. Записи сохраняются в `Видео/EVA Clips`; папку можно изменить в настройках.

## Управление

| Действие | Сочетание по умолчанию |
| --- | --- |
| Открыть / скрыть панель | Alt+X |
| Начать / остановить запись | Alt+F9 |
| Включить / выключить мгновенный повтор | Alt+Shift+F10 |
| Сохранить мгновенный повтор | Alt+F10 |
| Снимок PNG | Alt+F1 |
| Включить / выключить микрофон | Ctrl+Alt+M |

Сочетания меняются в настройках. Если другая программа уже заняла сочетание, измените его. Полный выход — через значок в трее; крестик скрывает панель.

Панель видна при захвате рабочего стола, на снимках и при демонстрации всего экрана. Она не скрывается автоматически при начале записи или снимке. Чтобы убрать её из кадра, нажмите Alt+X или Esc. Захват отдельного окна записывает только выбранное окно; для демонстрации панели вместе с игрой выбирайте весь экран. Приложение не обходит ограничения защищённого контента Windows.

## Настройки

- Рабочий стол / выбранная игра или окно через Windows Graphics Capture.
- Разрешение до 3840×2160, 30/60/120 FPS, H.264 или HEVC, 5–100 Мбит/с.
- Мгновенный повтор 1–60 минут в RAM; расчёт памяти в интерфейсе, предел 16 ГБ. Запись и буфер могут работать одновременно.
- Одна смешанная аудиодорожка; две отдельные дорожки (система и микрофон); до шести дорожек (система, микрофон, четыре выбранных приложения).
- Выбор аудиоустройств, отдельная громкость системы, микрофона и приложений. В многодорожечном режиме системный микс можно отключить, чтобы не дублировать звуки приложений.
- Папка сохранения, необязательный лимит места и срока хранения. Очистка затрагивает только файлы из собственной библиотеки приложения; закреплённые и самый новый файл сохраняются. Лимит не гарантирует строгое ограничение при закреплённых файлах или активной записи.
- Галерея записей и снимков. Для превью и длительности видео нужны `ffmpeg.exe` и `ffprobe.exe` в `PATH` или подпапке `tools`. Эти дополнительные программы не включены в архив; сама запись от них не зависит.

Качество захвата выбранного окна зависит от игры. Эксклюзивный полноэкранный режим может потребовать переключения игры в безрамочный режим. Для проверки используйте короткую запись. Несколько аудиодорожек удобнее проверять в видеоредакторе: обычный проигрыватель часто воспроизводит только одну.

## Локальные данные

Настройки, библиотека и миниатюры создаются в `%LOCALAPPDATA%/EVA Clipper 2`. Ядро OBS создаёт конфигурацию и журналы в `engine/config`. Записи лежат в выбранной пользователем папке. Эти данные не входят в репозиторий или опубликованный архив.

Управление OBS использует аутентифицированный WebSocket со случайным паролем и портом при каждом запуске. Клиент подключается к `127.0.0.1`; сервер OBS может слушать все IPv4-интерфейсы. Приложение не создаёт правил брандмауэра. Не публикуйте `engine/config`: там есть локальные пути, параметры устройств и пароль управления.

## Сборка

Используйте Windows, .NET Framework 4.8 и современный Roslyn `csc.exe` (например, из Visual Studio Build Tools). Старый компилятор из каталога Windows Framework не подходит.

```powershell
./scripts/build.ps1 -Compiler '<path-to-Roslyn>/csc.exe'
./scripts/package.ps1 -ObsZip '<downloads>/OBS-Studio-32.0.4-Windows-x64.zip' -ObsSource '<downloads>/OBS-Studio-32.0.4-Sources.tar.gz'
```

Скрипт упаковки проверяет SHA-256 официальных архивов и создаёт новую папку пакета, копируя только явно перечисленные файлы. Он не упаковывает установленное приложение и его конфигурацию. Не запускайте приложение внутри папки сборки релиза перед публикацией.
